# 跳跃

## 基础跳跃

跳跃在竖直方向上可以简化为玩家的上抛运动，只需要不断更新玩家受重力影响的速度，再根据速度更新其坐标即可，当玩家落地时将速度设置为零。

```cpp
// 在每一帧更新跳跃
player.velocity.y += gravity * delta_time;
player.position.y += player.velocity.y * delta_time;

// 检查是否着陆
if (is_on_floor(player))
    player.velocity.y = 0;
```

### 关键点 1：重力

受关卡和世界尺寸的限制，重力通常不会与现实世界相同。可以看出，重力越大，对速度的修改就越快，玩家就会更快地落地；重力越小，玩家下落越缓慢，手感上会更轻盈。

### 关键点 2：初速度

先检查起跳条件，再赋予初速度。

```cpp
// 检查是否满足跳跃条件，赋值跳起初速度
if (is_on_floor(player) && is_key_just_pressed("jump"))
    player.velocity.y = initial_jump_velocity;

// 在每一帧更新跳跃
player.velocity.y += gravity * delta_time;
player.position.y += player.velocity.y * delta_time;

// 检查是否着陆
if (is_on_floor(player))
    player.velocity.y = 0;
```

可以看出，重力不变的条件下，初速度越大，玩家跳起飞升的阶段就越快，在画面表现上会更有力，反馈更干净利索。

## 跳跃进阶

### 二段跳

比较简单的做法是添加一个计数器，用于计算在空中跳跃的次数。

```cpp
if (is_on_floor(player))
    double_jump_count = 0;

if (!is_on_floor(player))
{
    if (is_key_just_pressed("jump") && double_jump_count < 1)
    {
        player.velocity.y = initial_jump_velocity;
        double_jump_count += 1;
    }
}
```

也可以将二段跳的过程设置为状态机独立的状态，在满足二段跳条件时直接进行状态切换。

### 跳跃保持

玩家可以按住跳跃键一段时间，从而在跳跃的过程中跳到更高的位置。

```cpp
// 如果玩家仍在上升
if (player.velocity.y > 0)
{
    if (is_key_pressed("jump") && player.velocity.y < max_jump_velocity)
        player.velocity.y += additional_jump_force; // 持续加速跳跃
}
```

二段跳是对跳跃过程中速度的**瞬时修改**，跳跃保持是对跳跃过程中速度的**连续修改**。

### 限制最大跳跃高度

出于对关卡设计、难度调整的考虑，我们通常要设置角色跳跃的最大高度。

```cpp
// 玩家仍在上升
if (player.velocity.y > 0)
{
    // 检查是否达到最大高度
    if (player.position.y >= max_jump_height)
        player.velocity.y = 0;  // 强制停止跳跃，开始下落
    else
    {
        if (is_key_pressed("jump") && player.velocity.y < max_jump_velocity)
            player.velocity.y += additional_jump_force;  // 持续加速跳跃
    }
}

// 更新玩家垂直位置
player.position.y += player.velocity.y * delta_time;
```

同时为了防止到最大高度后直接下落造成的撞空气墙的手感，更进阶的方法是使用插值进行平滑，在玩家达到最大高度前根据当前运动的速度进行连贯的衰减。

## 优化秘籍

### 跳跃缓冲

允许玩家按下跳跃键后延迟执行跳跃动作。玩家在落地前一瞬间按下跳跃键，落地时也会自动起跳，避免“明明按了却没跳”的挫败感。

```cpp
// 按键按下时重置跳跃缓冲定时器
if (is_key_pressed("jump"))
    timer_jump_buff.restart();

// 当满足跳跃条件，并且跳跃缓冲存在时，自动触发跳跃
if (is_on_floor(player) && is_jump_buff_exist)
    player.velocity.y = initial_jump_velocity;
```

### 跳跃宽限期

常被叫做土狼时间（Coyote Time），允许玩家在离开平台的一小段时间内，仍然可以通过按键触发跳跃。

```cpp
// 在离开平台的这一帧重置定时器
if (is_on_floor_last_frame && !is_on_floor(player))
    timer_jump_forgive.restart();

// 当按键按下且跳跃宽限存在时，触发跳跃
if (is_key_just_pressed("jump") && is_jump_forgive_exist)
    player.velocity.y = initial_jump_velocity;
```
