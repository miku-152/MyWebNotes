# 移动

游戏角色控制中两个极为关键的课题：如何让角色移动手感与游戏玩法相匹配，和如何使用数学公式拟真角色移动惯性。

## 角色移动基础

游戏世界中角色移动的本质，其实就是在游戏的帧更新过程中，不断修改角色坐标的位置。

```cpp
void on_update()
{
    if (is_key_pressed(KEY_RIGHT))
    {
        player.position.x += speed;
    }
}
```

但若每帧移动固定的距离，那角色在游戏世界中的移动速度，就会与游戏的帧率挂钩，显然在大部分游戏设计中是不合理的。所以我们常将帧间隔作为参数纳入到计算过程中，让每帧角色移动的实际距离受现实中时间影响。

```cpp
void on_update()
{
    if (is_key_pressed(KEY_RIGHT))
    {
        player.position.x += speed * delta_time;
    }
}
```

但是如果斜方向上的移动向量直接使用两正方向合成，玩家的移动速度就会变为原来的 √2 倍，所以需要对速度矢量进行**归一化**后，再与移动速度相乘修改角色位置坐标。

```cpp
void on_update()
{
    Vector2 direction;
    direction.x = is_key_pressed(KEY_RIGHT) - is_key_pressed(KEY_LEFT);
    direction.y = is_key_pressed(KEY_UP) - is_key_pressed(KEY_DOWN);
    player.position += speed * delta_time * direction.normalize();
}
```

## 角色移动进阶

### 加速度

速度变化可以分为起跑、速度保持、刹车三个阶段。在加速的过程中，角色移动速度由 0 逐渐提高到最大速度；在刹车过程中再由最大速度降回到 0。

```cpp
float move_toward(float from, float to, float delta)
{
    if (from < to)
    {
        return min(from + delta, to);
    }
    else
    {
        return max(from - delta, to);
    }
}

void on_update()
{
    int direction = is_key_pressed(KEY_RIGHT) - is_key_pressed(KEY_LEFT);
    player.velocity.x = move_toward(player.velocity.x, direction * speed, acceleration * delta_time);
    player.position += player.velocity.x * delta_time;
}
```

但是，这样的设计并非完美且通用：在起跑与减速的过程中，用于修改速度大小的加速度，可能并不相同；有些游戏为了保证干脆利落的操作连招反馈，可能并没有加速减速的过程。以及，为了确保移动的物理驱动感，常常使用**非线性的加速度**来代替恒定的加速度值。

## 角色移动秘籍

### 非线性加速度

常用的非线性加速度模拟函数有两类：指数函数（`exp`）和对数函数（`log`）。

1.  **指数函数**：模拟起跑的加速过程时，初期加速缓慢，而后期加速较快；而减速过程中，初期减速较快且可以迅速接近目标速度。指数函数更符合现实生活中有动力驱动的运动，譬如车辆等载具，加速的过程中有持续的推力感，刹车的时候可以产生紧急制动的降速。
2.  **对数函数**：在模拟加速时初期加速较快而后期逐渐变缓；在模拟减速时，虽然也是先快后慢，但更为平缓，更像角色失去动力后在摩擦力的作用下，自动滑行至停止的效果。

### 加 / 减速相对占比

当加 / 减速过程都十分短暂甚至不存在时，就能实现更加细微的操作，使手感更贴合预期。

*   加速过程更长时，角色就会显得更为沉重和笨拙。
*   减速过程更长时，则会出现脚底打滑的感觉。
*   游戏角色负重时，同样可以通过调整加速减速的速度来实现。
