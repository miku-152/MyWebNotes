# 设计架构的追求目标：高内聚，低耦合

*   **高内聚**：每个模块内部的功能都是紧密关联的，不混杂其他的逻辑。
*   **低耦合**：模块之间的联系和依赖要尽量少。

设计模式永远只是指导思想，工程实践中如何落地代码实现，或是融会贯通组合使用，这都是合理的正确的。设计模式是方法论，不是限制设计能力的囚笼。我们总结出的设计模式术语与概念，是提供设计指导思路的提示，或是开发者之间沟通交流的凭据。
